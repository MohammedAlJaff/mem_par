# Reference

This folder collects non-canonical but still useful material in one place.

- `walkthroughs/` contains pedagogical runnable scripts that explain the core
  ideas in small pieces.
- `sanity/` contains smoke tests, teaching notebooks, and small checks that are
  useful before trusting larger experiments.
- `notebooks/` contains exploratory notebooks kept for local investigation and
  historical context.
- `archive/` contains older reference code that is worth preserving but is not
  part of the active experiment stack.

Reference material is maintained for pedagogy, local checking, and historical
context, but it is not the canonical source of truth for paper experiments.

Use this folder when you want to:

- teach or inspect a concept without touching the active study stack
- run a small sanity check before scaling up
- revisit older exploratory work

Do not route canonical runtime code through `reference/`.
