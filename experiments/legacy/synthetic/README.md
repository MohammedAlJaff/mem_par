# Synthetic Family

This family is archived reference material from the older experiment stack.

Canonical synthetic study work now belongs under `experiments/` and should use
the shared reusable code in `src/`.

- `low_d/`: low-dimensional synthetic systems where geometry is directly visualizable
- `high_d/`: high-dimensional synthetic systems with known latent structure
- `mnist/`: synthetic image-like data with controlled latent generation
