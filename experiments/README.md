# Experiments

This folder contains the live first-party study surfaces for the paper repo.

Principles:

- `src/` holds reusable code.
- `experiments/` holds runnable paper workflows.
- `prototyping/` stays scratch- and transition-oriented.
- `archives/` keeps legacy snapshots for context, not live imports.

The primary live study today is:

- `mnist/`
  notebook-first walkthrough plus the saved-run runner for official artifacts
